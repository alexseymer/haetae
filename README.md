# Haetae

> Working name, pending trademark clearance.

Haetae is an AI operator that watches your Docker servers and reports back in chat. It is one tool that also deploys apps and includes the metrics, alerts and security scanning that small teams otherwise run as a separate stack.

It is built for solo developers and teams of 2 to 10 running 2 to 20 Linux servers with Docker Compose, without Kubernetes or a dedicated ops person.

See the [one-page spec](docs/spec.md) for scope and acceptance criteria.
