# Guides

These guides each cover one task. They assume you have finished [Getting started](../getting-started/) and have a host such as hel1-prod enrolled.

- [Deploy from Git](./deploy-from-git): deploy the shop from a repository and have it redeploy when you push.
- [A domain with HTTPS](./domain-and-https): serve the shop at `shop.example.com` with a certificate.
- [Rolling back](./rolling-back): what happens when a deploy fails and how to go back by hand.
- [Understanding alerts and incidents](./alerts-and-incidents): what the messages mean and how to quiet them.
- [Asking the operator questions](./asking-the-operator): the chat question box and how to read an answer.
- [Summarising logs](./summarising-logs): the short digest of warnings and errors.
- [Watching vulnerabilities](./watching-vulnerabilities): software scans, security findings and image updates.
- [Chat commands](./chat-commands): what you can type to the bot.
